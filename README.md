# EDU+ Corp | Sistema de Gestión de Instituto

Este es el repositorio completo del sistema de gestión para el instituto **EDU+ Corp**, que incluye el sitio web público y el portal de administración/intranet.

## Estructura del Proyecto
-   `backend/`: Código fuente en Django (Python) que gestiona la base de datos y la lógica de negocio.
-   `frontend/`: Archivos HTML, CSS y JS para el sitio web público y portal.
-   `deploy/`: Scripts para el despliegue automático en servidores de producción.
-   `DOCUMENTACION/`: Contiene los manuales de usuario y técnicos creados para este proyecto.

## Documentación Requerida
-   **Manual de Instalación**: He creado el archivo [Manual_Instalacion.md](DOCUMENTACION/Manual_Instalacion.md) con los pasos para configurar el entorno.
-   **Manual de Usuario**: He creado el archivo [Manual_Usuario.md](DOCUMENTACION/Manual_Usuario.md) donde se explica cómo navegar por la web y usar la intranet.
-   **Manual Técnico**: He creado el archivo [Manual_Tecnico.md](DOCUMENTACION/Manual_Tecnico.md) detallando la programación y estructura del código fuente.

## Cómo comprimir el proyecto para entrega
Para generar el archivo final que incluya la web, el portal y el código fuente:
1.  Haga doble clic en el archivo `comprimir_proyecto.bat` situado en la raíz de este proyecto.
2.  Se generará automáticamente un archivo llamado `institute-management-system_final.zip`.
